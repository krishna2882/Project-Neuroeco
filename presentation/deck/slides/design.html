Design

Three games, payoffs fixed, only the message changes

Ultimatum game

A proposer splits the money; the responder accepts or rejects, and a rejection leaves both with nothing.

S1 · Responder

Accept or reject offers of 5–50%

S2 · Proposer

How much to offer

Dictator game

The same split, but the other player cannot reject, so giving shows pure generosity.

S2 · Dictator

How much to give, with no veto

Trust game

Every rupee sent is tripled; the partner then decides how much, if anything, to send back.

S3b · Investor

How much to send (trust)

S3a · Trustee

How much to return after 20, 50 or 100% was sent

Before each decision the partner sends a message: neutral, angry, sad or happy (5 each), or none · stakes INR 100 or 10,000

KRISHNA · 0:45 — We use three classic games. In the ultimatum game a proposer splits the money and the responder can reject, which leaves both with nothing; the model plays both roles. The dictator game is the same split without the veto, so any giving is pure generosity. In the trust game every rupee sent is tripled and the partner decides how much to send back; the model plays both the investor and the trustee. Before every decision the partner sends a message: neutral, angry, sad or happy, or no message. Next: how each condition is built.
