Design

Three games, payoffs fixed, only the message changes

Ultimatum game

A proposer splits the money; the responder accepts or rejects, and a rejection leaves both with nothing.

Dictator game

The same split, but the other player cannot reject, so giving shows pure generosity.

Trust game

Every rupee sent is tripled; the partner then decides how much, if anything, to send back.

KRISHNA · 0:45 — We use three classic games. In the ultimatum game a proposer splits the money and the responder can reject, which leaves both with nothing. The dictator game is the same split without the veto, so any giving is pure generosity. In the trust game every rupee sent is tripled and the partner decides how much to send back. The model plays four roles across them: the ultimatum responder, the proposer with and without a veto, and both sides of the trust game. Before every decision the partner sends a message: neutral, angry, sad or happy, or no message. Next: how each condition is built.
