Finding 3 · a pre-registered test of a confound

The sadness effect was really the described loss

In the main study every sad message described a life event (a bereavement). The follow-up used sad messages with no event: only bodily and behavioural cues.

Main study · sad message describes a loss

−0.91

Qwen-7B rejects unfair offers less

log-odds of rejection, 95% CI [−1.63, −0.18]

Follow-up · sad message, no event

−0.13

The effect disappears

95% CI [−0.51, +0.25] · pre-registered test F1 not supported (p = .26)

Interpretation

The model responded to the situation, not to the emotion

Like sympathy for someone who lost something, rather than a reaction to sadness itself.

Message-as-random-factor estimates for Qwen-7B in the ultimatum responder role. Anger, by contrast, replicated with event-free messages (F2), so anger is an emotion effect and sadness was an event effect.
