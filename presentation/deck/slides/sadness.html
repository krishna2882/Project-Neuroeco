DEVANSH · 0:35 — The third finding is a test of a confound. In the main study, after sad messages Qwen rejected fewer offers, 32 percent instead of 48 percent, but every sad message described a loss, and the effect was weak. With sad messages that describe no event, it is essentially zero: 48 percent against 51, and our pre-registered test is not supported. The two studies do not differ significantly, so the loss explanation is suggestive, not proven. Anger, by contrast, did survive the same test. If asked: in model terms the effect is −0.91 log-odds [−1.63, −0.18] in the main study and −0.13 [−0.51, +0.25] in the follow-up; the difference between the studies has p = .06.
