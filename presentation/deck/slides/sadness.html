Finding 3 · a pre-registered test of a confound

A weak sadness effect did not survive a test without the life event

In the main study every sad message described a life event (a bereavement). The follow-up used sad messages with no event: only bodily and behavioural cues.

Main study · sad message describes a loss

−0.91

Qwen-7B rejects unfair offers less

log-odds, 95% CI [−1.63, −0.18]; not significant after correction

Follow-up · sad message, no event

−0.13

No effect

95% CI [−0.51, +0.25] · pre-registered test F1 not supported (p = .26)

Interpretation

Possibly a reaction to the loss, not to sadness

Suggestive only: the two studies do not differ significantly (p = .06).

DEVANSH · 0:35 — The third finding is a test of a confound. In the main study Qwen rejected unfair offers somewhat less after sad messages, but every sad message described a loss, and that effect never survived strict correction. With sad messages that describe no event, there is no effect at all: minus 0.91 becomes minus 0.13, and our pre-registered test is not supported. The two studies do not differ significantly, so the loss explanation is suggestive, not proven. Anger, by contrast, did survive the same test. If asked: main-study effect corrected p = .75 under the stricter model (FDR-significant only in the original model); heterogeneity between studies p = .06.
