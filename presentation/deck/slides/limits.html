Scope

What lies outside this study

Frontier commercial models

We tested open-weight models from 3B to 14B on the university GPU cluster, plus one large model through a free API. GPT, Claude and Gemini were beyond the project’s budget.

Mechanism inside the model or brain

The study is behavioural. Model internals and neural data were out of scope, so the links to brain findings are analogies, not shared mechanisms.

Real stakes and repeated play

One-shot text games with hypothetical money, as in vignette studies with people. Repeated games, reputation and real incentives are future work.

Each is a natural next step: the same design, prompts and analysis code can be pointed at new models or games.

Code, data and pre-registrations: github.com/krishna2882/Project-Neuroeco

These boundaries come from the resources available to a two-person student project: GPU time on the university cluster and no paid API budget. The pipeline is model-agnostic, so adding a frontier model only needs an API key and credits.
