KRISHNA · 0:30 — Here is how each condition is built, using a real example: the trust game with an angry partner at 100 rupees. The same rules are written in four different wordings, and each is paired with four of our five angry messages, rotating which one is left out. That gives 16 prompts, each asked three times with fixed seeds, so 48 decisions. The neutral condition is built the same way, and the effect is the difference. So a result cannot come from one lucky wording or one particular message. If asked: across the main study each message appears in about 80% of conditions, and the statistics treat the message as a random factor.
